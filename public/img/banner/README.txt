Banner slider beranda (gambar jadi, teks/judul langsung di dalam gambar — seperti banner toko hobi).
Format .webp / .jpg / .png, ukuran 1200 x 660 px (rasio 20:11). Di desktop tampil 2 banner sekaligus.
File yang ada sekarang = PLACEHOLDER (kolase foto produk contoh). Ganti dengan desainmu, nama file tetap sama.

  preorder.jpg               -> "Pre-order dibuka"   (link: katalog pre-order; tampil kalau ada PO dibuka)
  fandom-{slug}.jpg          -> banner per fandom    (link: katalog fandom itu; fandom favorit user tampil duluan)
                                slug = nama fandom huruf kecil + tanda hubung, mis.
                                genshin-impact, honkai-star-rail, jujutsu-kaisen, project-sekai, blue-lock, identity-v
  baru.jpg                   -> "Produk baru"        (link: katalog)
  artis.jpg                  -> "Buka toko"          (link: daftar / buka toko; tidak tampil untuk artis & admin)

Kalau file tidak ada, slide itu dilewati (fandom baru tanpa banner tidak muncul di slider).

Gambar kartu "Jelajahi per fandom" ada di folder public/img/fandom/{slug}.jpg (rasio 4:3, mis. 480 x 360 px).
Fandom tanpa gambar memakai kartu gradasi bawaan.
